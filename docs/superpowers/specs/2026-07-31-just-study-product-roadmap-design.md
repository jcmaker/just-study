# just-study 제품 로드맵 설계

## 상태

2026-07-31 브레인스토밍에서 승인됨.

## 제품 정의

`just-study`는 사용자가 자료를 직접 준비하지 않아도 Codex 에이전트가 주제를 조사하고, 30회의 학습 과정으로 구성하고, 매일 가르치고 평가하는 오픈소스 self-host 학습 플랫폼이다.

강의 자료를 사용자가 올려 관리하는 기존 학습 대시보드와 달리, `just-study`의 핵심 차별점은 에이전트가 먼저 최고 품질의 자료를 조사·평가·교차 검증해 학습 과정을 만든다는 점이다.

## 확정된 제품 원칙

- 제품명과 Codex 스킬 호출 이름은 `just-study`와 `$just-study`다.
- 공식 클라우드 서비스 없이 오픈소스 self-host만 제공한다.
- 첫 제품은 단일 사용자 전용이다.
- 서버는 `127.0.0.1`에만 열고 로그인·가입·계정 모델 없이 사용한다.
- 외부 네트워크 접속은 현재 E2E 범위에서 제외한다. 추후 실제 수요가 생기면 외부
  바인딩보다 먼저 단일 소유자용 접근 보호와 HTTPS를 별도로 설계한다.
- 구조화 데이터는 self-host 서버의 SQLite에 저장한다.
- 긴 리서치·강의·회고는 로컬 Markdown, PDF와 첨부자료는 로컬 파일로 저장한다.
- 모든 영구 데이터는 하나의 `data/` 디렉터리 아래에 둔다.
- 리서치와 강의는 서버가 아니라 Codex의 `$just-study` 스킬이 실행한다.
- 서버는 웹 UI, API, MCP, 검증, 저장만 담당한다.
- Codex 흐름을 완주해 품질을 확인한 뒤 Claude를 같은 MCP 계약의 추가 클라이언트로 검토한다.

## 전체 기능 범위

완성된 제품은 다음 기능을 포함한다.

- 과정과 30일 목차
- 리서치 출처, 평가 점수, 교차 검증 기록
- 일일 강의, ELI5, 비유, 예제, 적용 활동
- 이해 확인 인터뷰, 퀴즈, 보충 학습, 회고
- 진도와 완료 상태
- 일정, 실제 강의 기록, 학습 주제, 과제, 할 일
- Markdown·PDF·첨부파일 관리
- 웹·모바일 브라우저 대시보드
- Codex용 MCP와 `$just-study` 스킬
- 로컬 및 Docker 기반 self-host
- 상태 확인, 백업, 복구

## 구현 단계

각 단계는 별도의 설계 문서, 구현 계획, 검증을 가진다.

### 1. 플랫폼 기반

Next.js 단일 애플리케이션, SQLite, 로컬 파일 저장, 공통 서비스 계층, 과정 껍데기 생성, 상태 확인을 구현한다.

설계 문서: `2026-07-31-just-study-platform-foundation-design.md`

### 2. 학습 엔진

30일 과정, 리서치 루브릭, 일일 학습 상태, 퀴즈·보충·회고 규칙과 저장 모델을 구현한다.

설계 문서: `2026-07-31-just-study-learning-engine-design.md`

### 3. Codex 연결

공통 서비스 계층을 MCP 도구로 공개하고 `$just-study` Codex 스킬이 리서치·강의·평가 흐름을 실행하도록 한다.

### 4. 학습 대시보드

과정, 오늘의 학습, 진도, 출처, 퀴즈와 회고를 웹과 모바일 브라우저에서 확인한다.
무결성을 해치지 않는 draft 과정 정보, 아직 답하지 않은 퀴즈 보기 선택, 제출 전 회고만
직접 편집한다. 공통 app shell과 동일한 컴포넌트 구조에서 Focus, Calm, Focus Dark,
Bubblegum, Terminal 다섯 테마를 제공하고 사용자가 제공한 black/white/red/yellow
테마를 기본 Focus로 사용한다.

> **ERRATUM (2026-08-02):** 원문은 테마 셋과 "draft 정보·제출 전 회고만" 편집
> 가능하다고 적었다. 퀴즈가 사지선다로 바뀌면서 아직 답하지 않은 보기 선택이
> 편집 대상에 추가됐고, 테마가 다섯으로 늘었다. 근거는
> `2026-07-31-just-study-dashboard-uiux-design.md`의 같은 날짜 ERRATUM에 있다.

설계 문서: `2026-07-31-just-study-dashboard-uiux-design.md`

### 5. 학습 관리 전체 기능

일정, 실제 강의 기록, 학습 주제, 과제, 할 일, PDF와 첨부파일 기능을 추가한다.
뽀모도로 타이머는 이 단계의 필수 인수 조건에는 넣지 않지만, 일정·과제와 연결되는
후속 집중 학습 세션 기능으로 남긴다. 수요가 확인되기 전에는 타이머용 테이블이나
추상화를 미리 만들지 않는다.

### 6. Self-host 완성

Docker 배포, 데이터 백업·복구와 업그레이드를 localhost 전용으로 완성한다. 로그인·
계정 시스템과 외부 네트워크 공개는 구현하지 않는다.

## 데이터 소유권

중복된 기준 데이터를 만들지 않는다.

- SQLite가 과정 상태, 현재 Day와 단계, 퀴즈 결과, 출처 점수, 일정, 과제, 파일 메타데이터의 기준이다.
- Markdown이 긴 리서치 본문, 강의 내용, ELI5·비유·예제, 사용자 회고의 기준이다.
- SQLite는 Markdown 경로와 체크섬을 저장한다.
- `progress.md`와 Markdown 안의 구조화 표는 SQLite에서 생성하는 사람이 읽기 좋은 스냅샷이며 입력 데이터로 사용하지 않는다.

## 현재 제외 범위

- 공식 클라우드 SaaS
- 다중 사용자, 가입, 조직, 역할별 권한
- 서버 자체의 OpenAI·Anthropic·로컬 모델 호출
- Claude 지원
- 결제와 사용량 과금
- 알림, 게임화, 분석 대시보드
- 외부 네트워크 공개와 그에 필요한 인증·세션

실제 수요가 확인되기 전에는 이 기능을 위한 추상화나 데이터 모델을 미리 만들지 않는다.

## 참고 프로젝트와의 관계

OpenStudy는 self-host 운영 방식과 학습 관리 기능을 이해하기 위한 참고 프로젝트다. `just-study`는 독립 제품과 독립 코드베이스로 구현한다. OpenStudy 코드를 복사하거나 파생할 경우 MIT 저작권 고지 조건을 별도로 준수하지만, 현재 설계는 코드를 재사용하지 않는다.
