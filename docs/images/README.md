## 찍기 전 준비

빈 데이터로 찍으면 화면이 허전합니다. 과정이 몇 개 있는 상태에서 찍으세요.
직접 만든 학습 데이터가 있으면 그대로 쓰면 되고, 없으면 서버를 띄운 뒤 Codex에서
`$just-study`로 과정 하나를 만들어 Day 1까지 진행해 두면 충분합니다.

```bash
npm run dev
```

## dashboard-today.png

1. 진행 중인 과정의 `오늘` 탭을 엽니다 (`/courses/<id>?tab=today`)
2. 브라우저 창을 1280px 폭으로 맞춥니다
3. 목표 카드와 단계 표시(`강의 → 퀴즈 → 보완 학습 → 회고 → Day 완료`)가 함께 보이도록 스크롤합니다
4. macOS에서는 `⌘⇧4` 뒤 스페이스바로 창 전체를 찍습니다

퀴즈 단계에서 찍으면 사지선다 폼까지 함께 담겨 제품을 설명하기 좋습니다.

## themes.png

같은 화면을 다섯 테마로 찍어 이어 붙입니다. `/settings`에서 테마를 바꿔 가며
같은 위치·같은 스크롤로 찍어야 비교가 됩니다.

다섯 장을 다 넣으면 세로로 길어지니, Focus·Bubblegum·Terminal 세 장만 골라
가로로 붙이는 편이 읽기 좋습니다.

## codex-flow.gif

이 저장소에는 GIF를 만드는 도구가 없습니다. 화면 녹화 후 변환이 필요합니다.

macOS 기본 도구만 쓴다면 `⌘⇧5`로 화면 일부를 녹화해 `.mov`를 얻은 뒤,
ffmpeg가 있는 환경에서 변환하세요.

```bash
ffmpeg -i recording.mov -vf "fps=12,scale=1000:-1:flags=lanczos" -loop 0 codex-flow.gif
```

담을 장면은 이 정도면 충분합니다.

1. Codex에 `$just-study 계속` 입력
2. 에이전트가 저장된 Day와 단계를 읽어 오는 부분
3. 문제를 제시하고 답을 받는 부분
4. 브라우저로 전환해 같은 진도가 반영된 화면

10~20초, 5MB 이하를 권합니다. GitHub에서 큰 GIF는 로딩이 눈에 띄게 느립니다.
